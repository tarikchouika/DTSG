# أونو — DTSG

لعبة أونو كاملة القواعد بهوية المنصة: ضد البوت (3 مستويات) أو 4 لاعبين محلياً على جهاز واحد
(تسليم يد لكل لاعب) أو أونلاين بغرف DTSG (2-4 مقاعد، الرهان بين اللاعبين فقط).

## تشغيل تجريبي مستقل (بلا المنصة)
```bash
# أي خادم ثابت، ثم افتح:
#   uno-game/index.html
python3 -m http.server 8000
```
الصفحة المستقلة تحمل السكربتات بالترتيب: `uno-core → uno-game → uno-audio → uno-i18n →
uno-renderer → uno-html → uno-app` (الجسر `uno-bridge.js` اختياري — لربط المنصة فقط).

## الملفات
- `js/engine/` — المحرك الحتمي + سير المباراة + الذكاء الاصطناعي (بلا DOM).
- `js/ui/` — الصوت، i18n (4 لغات)، راسم SVG، بنية الشاشات، المتحكم.
- `uno-bridge.js` — عقد المنصة: `eUno/initUno/cleanupUno` + معالجات الغرف.
- `css/uno.css` — هوية معزولة ببادئة `un-`.
- `tests/test-engine.js` — 25 تحقّقاً آلياً.
- `INTEGRATION.md` — دليل الدمج الكامل (خطوات + عقد الغرف + نتائج QA).
