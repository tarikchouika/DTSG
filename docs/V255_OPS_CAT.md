## 2. خطوات العمل المطلوبة على الهاتف (Termux / Phone Ops) 🛠️

### الخطوة 1: جلب التحديثات في الهاتف
```bash
cd ~/DTSG
# جلب أحدث التغييرات من الفرع الرئيسي
git pull origin main
```
*(أو في حال استعمال ملف الرقعة التراكمي: `git apply /path/to/DTSG-v255.patch`)*

### الخطوة 2: إعادة تشغيل خادم Node المحلي على الهاتف
بما أن التحديث يشمل ملفات الخادم ومحركات الألعاب المخدومة، يجب إعادة تشغيل عملية Node:
```bash
# إيقاف العملية القديمة إن كانت تعمل
pkill -f "node.*server.js" || true

# إعادة تشغيل السيرفر بدعم SQLite التجريبي
node --experimental-sqlite server.js &
```
التحقق من صحة الخادم المحلي في الهاتف:
```bash
curl -s http://127.0.0.1:3000/api/health
# يجب أن يرجع: {"ok":true,"service":"dmgames-arena","build":"2.45.0",...}
```

### الخطوة 3: نشر الواجهة الثابتة على Cloudflare Pages (dtsg.pages.dev)
يتم النشر من الهاتف حيث يتوفر مفتاح التوكن الآمن (الذي لا يُخزن في المستودع العام):
```bash
export CLOUDFLARE_ACCOUNT_ID=758fcc827f3338772847c28391b6c6c3
export CLOUDFLARE_API_TOKEN="<التوكن_الخاص_بك_في_الهاتف>"

# تشغيل سكربت النشر الآلي
bash scripts/deploy-pages.sh
```
*السكربت يقوم تلقائياً ببناء وتصفية الملفات إلى `/tmp/dmc-deploy` ورفعها إلى مشروع `dtsg` على فرع `main` ليعمل الرابط مباشرة: `https://dtsg.pages.dev`.*

## 3. قائمة التحقق السريعة لـ cat (Smoke Test Checklist) 🧪

1. **الضومنة (Dominoes)**:
   - افتح لعبة الضومنة (4 لاعبين): تأكد أن الدور يتحرك **عكس عقارب الساعة** (اللاعب الرئيسي ⬅️ الخصم الأيمن ⬅️ الخصم العلوي ⬅️ الخصم الأيسر ⬅️ اللاعب الرئيسي).
   - تأكد أن شارة اللاعب الرئيسي متمركزة في **الوسط أفقياً فوق قطع يده** وتحتوي أول حرفين من اسمك (مثل `TA` أو `PL`).
   - تأكد أن قطع الخصم الأيسر ملاصقة لحافة الشاشة اليسرى، وأيقونته تقع إلى يمين قطعه متجهة نحو الطاولة.
   - تأكد أن بنك القطع نزل قليلاً وله متنفس أسفل بطاقة `R T`.

2. **الرامي (Rami)**:
   - ابدأ مباراة رامي: لا مزيد من تجمّد العداد عند 0 ثانية إطلاقاً.
   - البوتات لا ترتكب مخالفة سحب المرموق (+71 نقطة جزاء).

3. **سلامة النفق (Cloudflare Tunnel)**:
   - سكربت `scripts/phone-tunnel.sh` يواصل ربط هاتف المشرف بسلاسة دون تعارض.
