# مواصفة واجهات إعدادات الألعاب (مرجع للمساعدات الآلية) — v2.39

هذه الوثيقة مرجع إلزامي لأي تعديل قادم على نوافذ إعدادات الألعاب أو الترجمات،
حتى تبقى الواجهات موحّدة ومميزة آلياً. آخر تحديث: 2026-09-17.

## 1) المرجع البصري: بطاقة إعدادات «روندا الكلاسيكية»
كل نوافذ إعدادات اللعب ضد الآلي / وجهاً لوجه (فلات دوغ، رامي، بارتشي، روندا،
ضاما، شطرنج، بلياردو×5، دومينو، طاولة) يجب أن تتبع نفسgrammar البصري:

- **الحاوية**: بطاقة داكنة بحد ذهبي خارجي + حد داخلي رفيع (`::before` inset 6px).
- **حقل الإعداد** (`.dama-field / .dm-field / .bw-field / .rami-field / .bets / .rd-menu-section`):
  خلفية `rgba(11,21,38,.45)`، حد `rgba(226,184,87,.35)`، زوايا 14px، حشو 10-12px.
- **عنوان الحقل** (`.dama-flab / .dm-flabel / .bw-flabel / .rami-field-label / .rd-menu-label`):
  ذهبي، .78rem، وزن 800، تباعد أحرف 1px، ويتبعه خط متلاشٍ (`::after`).
- **الخانات** (select / input رقمي): تدرج `--bg3→--bg2`، حد `--ctl-bd`، زوايا 12px،
  ارتفاع أدنى 42px، عند focus حد ذهبي + توهج `0 0 0 3px rgba(217,180,92,.18)`.
- **شرائح الاختيار** (`.dama-chip / .dm-segbtn / .bw-segbtn / .pr-chip / .bbtn`):
  أقراص pill؛ الحالة المختارة تدرج ذهبي بنص داكن غامق.
- **زر البدء**: تدرج ذهبي كامل العرض، نص `#20180a` وزن 900؛ زر الغرف `.ch-online`
  داكن بحد ذهبي نص ذهبي.
- **تلميح التدريب المجاني**: `.gset-free` — نص `ui.trainingFree` عبر `data-i18n`
  (لا يُكتب نص عربي معلّب أبداً).

القواعد كاملة في `css/03-components.css` كتلتا `[GSet-Unify v2.38]` و`[GSet-Ref v2.39]`.

## 2) قاعدة الرهان (سياسة المنصة)
- لا خانة رهان ولا مضاعفات في إعدادات الآلي/المحلي — **تدريب مجاني دائماً**.
- الرهان يُحدَّد حصرياً من فاتح الغرفة في إعدادات الغرف أونلاين.
- أي نافذة إعداد جديدة: ضع `data-i18n="ui.trainingFree"` مكان سطر الرهان.

## 3) قاعدة الترجمة (ممنوع الخلط اللغوي)
- كل نص ظاهر للمستخدم يدخل عبر `data-i18n` / `data-k` / `T()` — **لا نصوص معلّبة**.
- الصفحات القانونية (الاسترداد وغيرها): قاموس `D` محلي بأربع لغات ar/fr/en/da
  يغطي كل عنصر `[data-k]` بما فيه صفوف الجداول (مفتاح لكل صف يحتوي خلايا HTML).
- المحفظة: مفاتيح `wl.*` في `js/i18n/translations.js` (تُبث عبر `translateStatic`).
- عند إضافة لغة/نص: حدّث القاموس الرباعي كاملاً، وشغّل مجس `tests/_verify_batch.js`
  للتأكد من `RAW-KEYS: []`.
