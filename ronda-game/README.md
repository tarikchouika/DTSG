# الـرونـدا — Ronda Game

لعبة **الروندا المغربية التقليدية** كاملة كتطبيق ويب مستقل، مبنية على معمارية
**RONDA GAME CORE** الاحترافية: محرك حتمي (Deterministic) مستقل عن الواجهة،
نظام أوامر (Commands) وأحداث (Events)، جاهز للضم إلى منصة أونلاين.

---

## التشغيل

**لا يحتاج أي تثبيت أو خادم:**

1. فك ضغط المجلد.
2. افتح `index.html` في أي متصفح حديث (Chrome / Edge / Firefox / Safari).

> يعمل على الحاسوب والجوال، وبدون اتصال بالإنترنت.

## أنماط اللعب

| النمط | الوصف |
|---|---|
| **ضد الكمبيوتر** | أنت ضد ذكاء اصطناعي يفهم الالتقاط والضربة والحبل والميسا |
| **لاعبان** | لاعبان يتناوبان على نفس الجهاز |
| **زوجان ضد زوجين** | 4 لاعبين، فريق أ (المقعدان 1 و3) ضد فريق ب (المقعدان 2 و4) |

- **هدف الفوز قابل للاختيار**: 41 / 51 / 61 نقطة.
- **حماية خصوصية الأوراق** (مفعّلة افتراضياً): عند تغيّر الدور تظهر شاشة
  "حان دورك — أظهر أوراقي" حتى لا يرى اللاعبون أوراق بعضهم.
  يمكن تعطيلها من شاشة البداية للعب العائلي المفتوح.

## القواعد المنفذة

- 40 ورقة: 4 أنواع (**الخال، الكوباس، شبادا، دهاب**) × رتب 1-7 و10-12 (لا 8 ولا 9).
- الموزع يوزع 3 أوراق لكل لاعب ثم 4 مكشوفة على الطاولة، **والخصم يبدأ دائماً**.
- الالتقاط: الورقة الملعوبة تلتقط كل نسخ رتبتها على الطاولة **+ كل السلسلة المتتابعة**
  `1→2→3→4→5→6→7→10→11→12` حتى أول رتبة مفقودة (الترتيب بالرتب لا بمواقع الأوراق).
- **ضربة** +1: لعب نفس رتبة آخر ورقة لعبها الخصم مباشرة.
- **حبل** +5: رد صاحب الورقة الأصلية بنفس الرتبة بعد الضربة.
- **جوج حبال** +10: لعب الورقة الرابعة من صاحب الضربة بعد الحبل.
- **ميسا** +1: التقاط كل أوراق الطاولة.
- **روندا** +1 / **تريندا** +3: إعلان عند بداية كل توزيعة؛ الأقوى يفوز
  (تريندا > روندا ثم الرتبة الأعلى) ويأخذ مجموع نقاط كل الإعلانات.
- نهاية الجولة: الأوراق المتبقية على الطاولة لآخر ملتقط؛
  كل ورقة فوق 20 = نقطة (في الزوجين: مجموع أوراق الفريق فوق 20).
- **قاعا راي** +5: الموزع يلتقط 12 برميته الأخيرة.
- **قاعا أص** +5: الموزع يلتقط 1 — أو لا يلتقط شيئاً — برميته الأخيرة (للخصم).
- الفوز: أول فريق يبلغ الهدف المتفق عليه.

> ملاحظات تفسيرية موثقة في الكود حيث ورد أكثر من تفسير محلي ممكن،
> وكلها قابلة للتغيير من `RondaRulesConfig` دون تعديل المحرك.

### مبادئ المحرك

1. **حتمي ببذرة (Seeded)**: نفس `seed` + نفس الأوامر = نفس المباراة حرفياً
   (اختبار الحتمية مضمّن في الاختبارات) — أساس الـ Replay ومكافحة الغش.
2. **Server-Authoritative**: العميل يرسل `playCard(playerId, cardId)` فقط؛
   المحرك يقرر الصلاحية والالتقاط والنقاط ويُصدر أحداثاً.
3. **لا تسريب معلومات**: `game.getView(playerId)` لا يُظهر يد الخصم ولا محتوى
   الرزمة أبداً (عددهم فقط) — وهو ما يجب أن يرسله الخادم لكل عميل.
4. **Snapshot كامل**: `game.getSnapshot()` للخادم (يحوي كل الأيدي).
5. **الأحداث**: كل ما يحدث يصدر كحدث متسلسل (`CardPlayed`, `CardsCaptured`,
   `Strike`, `Rope`, `DoubleRope`, `Mesa`, `DeclarationsResolved`, `Qa3aRey`,
   `Qa3aAs`, `ScoreChanged`, `RoundEnded`, `GameEnded`...) — نفس الأحداث تكفي
   لواجهة الويب هذه أو Unity أو تطبيق جوال.

### مثال الدمج في خادم أونلاين (Node.js)

```js
const RC = require('./js/engine/ronda-core.js');
const { RondaGame, RondaAI } = require('./js/engine/ronda-game.js');

const game = new RC.RondaGame({
  mode: RC.GameMode.HEAD_TO_HEAD,
  seed: 12345,                       // بذرة المباراة (للـ Replay)
  rules: new RC.RondaRulesConfig({ targetScore: 51 })
});

game.onEvent(ev => io.to(room).emit('ronda-event', ev)); // بث الأحداث للاعبين

// لاعب يطلب لعب ورقة — الخادم يتحقق فقط:
try {
  game.playCard(new RC.PlayCardCommand(playerId, cardId));
} catch (e) { /* حركة غير قانونية */ }

// لكل عميل يُرسل View فقط:
socket.emit('state', game.getView(playerId));
```
