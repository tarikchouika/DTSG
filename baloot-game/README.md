# البلوت (Baloot) — DTSG

لعبة ورق كاملة القواعد بهوية المنصة (كحلي زليج × ذهب دكاء) — مدمجة بالكامل في المنصة.

- **الأوضاع:** ضد البوت (3 مستويات) · 4 لاعبين محلي (تسليم الجهاز) · **غرفة أونلاين 4 لاعبين + بطولات**
- **الرهان:** بين اللاعبين في الغرف فقط (تسوية خادم للفريق الفائز ×2) — وضعي البوت والمحلي تعليمي مجاني
- **القواعد:** تسمية (هوكم/صن/بس) · أشور (سرا/خمسين/مية/رباعية + قطع) · بلوت · اليد +10 · كابوت — تُعرض من أيقونة الكتاب بهيدر اللعبة (بلا زر قواعد داخل اللعبة)
- **سلوك الغرف:** سائق = المضيف (بذرة موحّدة) · تولى المقاعد المنقطعة بالذكاء حسب مؤقت الغرفة · تصويت بوابة الجولات · ريماش · إعادة بناء كاملة من السجل (`applyRoomReplay`)
- **العقد:** `eBaloot / initBaloot / cleanupBaloot / blMyUserId` — نفس نمط الطاولة والضومنة
- **التفاصيل:** [`INTEGRATION.md`](INTEGRATION.md) — خطوات الدمج الحرفية + عقد الغرف + الاختبارات

## تجربة سريعة (بدون المنصة)
افتح `index.html` في المتصفح — قائمة إعدادات كاملة ومباراة مجانية.
